# 手机单个与批量保存

iPhone / iPad 支持文件级 Web Share 时，单个“保存”和“保存全部”都可调用系统面板，供用户选择相册、文件或其他应用；实际选项由系统和文件类型决定。

传给系统的是原始 File 对象，保留名称、MIME 类型和字节，不重新编码，不添加网页链接，不上传到服务器。文件提前准备，点击的同一次用户手势内调用系统接口，避免读取文件后手势已失效。

准备池总计最多 64 MiB，优先当前接收，再准备历史暂存；这只是系统面板准备上限，不是传输大小限制。大批次中的小文件仍可单独使用面板。文件过大、接口缺失或不支持该批次时，保留普通下载与逐个确认入口。

“保存全部”无法一次交给系统时，逐个确认窗口每次提供一个原文件。用户点击后再进入下一份，避免手机浏览器默默只下载第一份。桌面 Chrome / Edge 仍可使用浏览器允许的批量下载方式。

取消面板不自动触发下载、不标记已保存；其他系统错误由下一次用户点击再走普通下载。系统成功返回只表示已交给系统，不证明目标应用已完成落盘。清理暂存前应确认文件已保存。

重置、过期、清理或文件列表变化会取消旧的准备和队列，迟到的系统结果不能标记新会话。保存为相关暂存文件续期，期限见[暂存规则](safari-storage.md)。

自动检查验证传给系统的文件名、类型、摘要、有效手势、取消和迟到结果；系统面板由测试接口替代，不能代替真实 iPhone 系统保存验证。接口约束见 [Web Share](https://www.w3.org/TR/web-share/)。

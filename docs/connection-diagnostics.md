# 连接诊断

仅带 `?connection-debug=1` 的页面启用。普通页面不采样、不显示面板、不附带诊断计数。诊断分享链接保留参数；普通扫码页不会仅因读到该参数而自动启用采样。

页面底部提供本机 JSON 导出，没有报告上传接口，也不持久存入浏览器。刷新或关闭后记录消失。本机每个活动连接每秒最多采样一次，最多 12 条记录、每条最近 120 个样本，完成／取消后停止。

| 指标 | 含义与边界 |
| --- | --- |
| `generation`、连接状态、`recovering` | 观察重复建链与恢复，不改变连接策略 |
| `confirmed`、`recentBps`、`averageBps` | 已写入进度、近期速率、累计平均速率，不能互相替代 |
| `buffered`、`inFlight`、`queued`、`window` | 浏览器缓冲、未确认数据、接收队列和应用窗口；不是原生拥塞窗口 |
| 读／写字节及耗时 | 累计读取与校验、校验与写盘时间，不是纯磁盘耗时 |
| 原生协议、候选与地址分类 | UDP／TCP、host／srflx／prflx 与私网／共享／公网／mDNS；不保留具体地址 |
| `stunRoundTripMs`、`nativeAgeMs` | 浏览器候选对往返值与缓存快照年龄，不等于 SCTP RTT 或丢包率 |
| 字节／包计数与发送丢弃数 | 累计值可能包含协议开销；不能直接当作文件有效流量或端到端丢包率 |
| `hidden`、`peerHidden` | 本端与对端是否在后台，不读取其他应用 |

对端匿名数值只通过当前加密通道的既有 ping／pong 携带，每 10 秒最多一次；未启用的一端不记录、不回传。转发路线不沿用旧 WebRTC 计数。所有字段经过允许清单和数值边界过滤，不保存文件名、内容、分享密钥、房间号、候选 ID、具体 IP、UA 或原始控制台日志。

判断瓶颈时区分源读取、处理排队、实际所选路径和落盘；不能只凭平均速度归因运营商。不同时间／设备的结果不能直接证明某个版本普遍更快。
